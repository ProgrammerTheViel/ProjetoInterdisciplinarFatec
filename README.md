# NutriQUACK

Projeto de extensão desenvolvido no curso de Informática para Negócios da Fatec São José do Rio Preto.

## Sobre o projeto

O NutriQUACK é uma proposta de sistema para apoiar profissionais de nutrição no cadastro e acompanhamento de pacientes, no registro de avaliações físicas e na elaboração de planos alimentares.

O escopo documentado prevê organizar refeições, alimentos, porções e informações nutricionais, além de gerar um plano alimentar em PDF.

## Situação atual

O projeto está na fase de documentação, modelagem do banco de dados e prototipação visual. Nesta etapa, não é necessário apresentar um sistema funcionando. A implementação e os testes serão realizados posteriormente.

## Tecnologias e materiais

- Java, para a futura implementação do sistema.
- SQL Server, para a modelagem e os dados de exemplo do banco.
- Protótipos visuais das principais interfaces.
- Diagramas e documentação do projeto.
