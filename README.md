# NutriQUACK

Projeto de extensão desenvolvido no curso de Informática para Negócios da Fatec São José do Rio Preto.

## Sobre o projeto

O NutriQUACK é uma proposta de sistema para apoiar profissionais de nutrição no cadastro e acompanhamento de pacientes, no registro de avaliações físicas e na elaboração de planos alimentares.

O escopo prevê organizar refeições, alimentos, porções e informações nutricionais, além de permitir a geração de um plano alimentar em PDF em uma etapa futura.

## Situação atual

O projeto está na fase de documentação, modelagem do banco de dados e prototipação visual. O repositório já contém classes Java que representam os dados principais do domínio e um script SQL para a estrutura e os dados de exemplo do banco.

Nesta etapa, não é necessário apresentar um sistema funcionando. As funcionalidades, os testes e as instruções de execução serão desenvolvidos posteriormente.

## Como explorar o projeto

1. Consulte as classes Java em `NutriQUACK/src/`. Elas representam elementos como pacientes, nutricionistas, avaliações físicas, planos alimentares, refeições e alimentos.
2. Consulte `NutriQUACK/banco_nutriquack.sql` para ver a criação das tabelas e os dados de exemplo do banco.
3. Se preferir baixar os arquivos juntos, use `NutriQUACK/NutriQUACK.zip`.

As classes Java atuais representam a estrutura de dados do projeto. Elas ainda não formam, por si só, uma aplicação executável.

## Tecnologias e materiais
